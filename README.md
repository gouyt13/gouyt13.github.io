# Yutong Gou — personal homepage

An academic homepage and blog built for GitHub Pages.

## Preview locally

The homepage is plain HTML and CSS. From this directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

Blog pages are generated by Jekyll, so this preview does not show them. To
preview the blog, install Jekyll and run `jekyll serve`, or push and view the
deployed site.

## GitHub Pages

This repository is configured as the user site `gouyt13.github.io`. GitHub
Pages builds the site with Jekyll from the root of the `main` branch.

The site is available at `https://gouyt13.github.io/` after GitHub finishes a
deployment.

## Customize

- Biography, publications, and links are in `index.html`.
- Colors, typography, and layout are in `styles.css`.
- The homepage does not require JavaScript.
- The homepage uses the public GitHub avatar endpoint at
  `https://github.com/gouyt13.png`, so it follows future GitHub avatar changes
  automatically.

## Blog

Posts live in `_posts/` as Markdown files named `YYYY-MM-DD-short-title.md`.
Each post is published at `/blog/short-title/` and listed on `/blog/`.

```markdown
---
title: "Post title"
description: One sentence shown under the title in the post list.
math: true
---

Inline math uses double dollars: $$O(1/\sqrt{D})$$.

$$
\langle \mathbf{o}, \mathbf{q} \rangle \approx \frac{\langle \bar{\mathbf{o}}, \mathbf{q} \rangle}{\langle \bar{\mathbf{o}}, \mathbf{o} \rangle}
$$
```

- `description` is optional.
- Set `math: true` only on posts with formulas; it loads KaTeX on that page.
  Both inline and display math use `$$ ... $$`; a formula in its own paragraph
  is displayed on its own line. Single `$` is not supported.
- Do not type a bare `|` in inline math: the paragraph is parsed as a table.
  Write `\lvert x \rvert`, `\lVert x \rVert`, or `\mid` instead.
- Fenced code blocks with a language name are syntax-highlighted.
- Files in `_drafts/` are not published.
- The post layouts are in `_layouts/` and the blog styles are in `blog.css`.
