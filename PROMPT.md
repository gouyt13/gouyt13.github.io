# Homepage redesign prompt

Redesign Yutong Gou's academic homepage with calm, restrained minimalism. The
page should feel like a well-typeset research profile—not a startup landing
page or design portfolio.

Use a quiet off-white background, near-black text, one muted blue accent,
generous whitespace, modest type sizes, thin rules, and a narrow readable
content width. Remove decorative illustrations, marquees, oversized
typography, cards, shadows, animation, sales language, and visual effects. Use
the GitHub raven avatar at a modest size.

Prioritize biography, research interests, selected publications, and
open-source software in a direct information hierarchy. Keep publication
metadata easy to scan, emphasize Yutong Gou's name without visual noise, and
provide understated links to Scholar, GitHub, DBLP, and the NTU research group.

Build with semantic, dependency-free HTML and CSS. The result must be
responsive and accessible, with no JavaScript unless strictly necessary.
Preserve only publicly available professional information.
